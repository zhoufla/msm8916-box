安装方式

        

          走 relay-helper 的 root 通道执行 pm install -r -d …; sleep 2; am start …
          （装包会杀进程，两条必须拼在同一条命令里），装完自动拉起；
          helper 不可用时退回系统安装器，需手动点确认；都不行就把 APK 留在
          /sdcard/Download 用 adb 装。
        

        
cloud build：git tag v1.2.0 && git push --tags 触发 GitHub Actions，编译签名后自动发 Release
