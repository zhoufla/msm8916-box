DDNS 动态域名

      

        

        把当前可达地址推给 DDNS 服务：station 模式报 NAT 出口 IPv4；IPv6 直报全球单播地址（蜂窝 IPv4 是运营商 CGNAT，不可达时不误报）。变更才更新，每条记录独立比对与推送，失败走告警推送。服务商与 Token 公共一份，解析记录可加多条。
      

      

        
        
        
        
      

      

      

        解析记录（每条 = 域名 + 网卡 + 记录类型）
         
      

      

        
域名网卡（必选）记录类型当前 v6当前 v4已推送状态

        
      

      
网卡必须选择，下拉项来自设备当前在线网卡（可在「概览 → 网卡」查看 IPv4 / IPv6）；不再支持留空自动。记录类型 v4=仅 IPv4、v6=仅 IPv6、both=两个都推。Cloudflare 按 A/AAAA 记录自动增改（TTL 300）。每次更新都计入系统日志。

          /sdcard/Download 用 adb 装。

ADB 调试通道（第二管理通道）

        
读取中…

        

        

          
          
          
          本机固定使用网络 adb（TCP 5555）。重启会断开当前 adb 连接并清掉半开连接；不影响 8080 面板。R=Recv-Q / S=Send-Q，ESTABLISHED 且队列非空即半开连接。切到 TCP 需二次确认。USB adb 不由面板启用：原厂 gadget 规则有缺陷，需要 tools/hwfix/usbadb/enable.sh，且启用后 5555 会 offline。
        

        

      


      

        
LTE 保活

        
读取中…

        

          

          WiFi 做上行时额外保持一条 MOBILE_HIPRI 链路，空闲态定时发包，避免基带漏寻呼导致短信延迟
        

        

          
          
          
          
        

        
        
10 秒间隔约 0.5 MB/天；SIM 没有流量或不想耗流量时关掉。保存后经 RelayService.wake() 立即生效，不用重启服务。

      


      

        
告警推送

        

          

          体检判据（modem SSR / RIL / SIM / 内存 / 面板 / 进程）、流量配额、保活重建等状态翻转时经通道推送（合成 ALERT 消息，复用短信转发通道，不进转发记录）
        

        

          
          
          
          
          
        

        
        
状态翻转才推送 + 每 remindH 小时重复提醒一次 + 恢复时通知；保活重建/恢复是即时事件，不受检查间隔限制。
